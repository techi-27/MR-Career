Accessibility

MR.Career aims to make career planning clear and usable with readable text, keyboard navigation, responsive layouts and visible focus indicators. Some pages or interactive controls may not yet fully meet every accessibility standard.

Using the app

  • Use Tab and Shift+Tab to move between controls, and Enter or Space to activate buttons.
  • Use the skip-to-content link when available.
  • Use the theme control to switch the application's light or dark appearance where supported.
  • Zoom in when needed; the layout is designed to adapt to smaller screens.

Report an accessibility barrier

If you encounter a barrier, please report it through the Contact page. Helpful details include the page you were using, what you expected to happen, your browser and whether you were using a keyboard or assistive technology.

Accessibility should be tested with keyboard-only navigation, zoom, screen readers and mobile devices before making a conformance claim.
