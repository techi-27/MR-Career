Accessibility

MR.Career aims to support readable text, keyboard navigation, responsive layouts and clear focus indicators. Some pages or interactive controls may not yet fully meet every accessibility standard.

Using the app

  • Use Tab and Shift+Tab to move between controls and Enter or Space to activate buttons.
  • Use the skip-to-content link when available.
  • Use the theme control to switch the application's light/dark appearance where supported.

If you encounter a barrier, please report it through the Contact page. Accessibility should be tested with keyboard-only navigation, zoom, screen readers and mobile devices before making a conformance claim.
